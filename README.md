# GRC Portfolio | Kuan

## About Me

I am a cybersecurity student building practical skills in Governance, Risk, and Compliance (GRC).

My focus is on understanding cybersecurity risk, assessing security controls, documenting compliance requirements, and supporting audit readiness.
